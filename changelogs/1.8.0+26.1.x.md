# Immersive Storms 1.8.0: Changes to sandstorms

Sandstorms are now more differentiated between rain and thunder.

- Sandstorm fog during 'rain' weather events is now lighter. 
- Added a new quieter and softer wind sound.
- Sandstorm wind sounds during 'rain' weather events now use the soft wind sound.
- Dense fog in Swamps, Dark Forests, and Pale Gardens is now less oppressive.
