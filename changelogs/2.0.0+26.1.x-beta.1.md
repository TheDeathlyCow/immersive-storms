# Immersive Storms 2.0.0 for Minecraft 26.1.x

Immersive Storms has undergone some major rewriting and refactoring to make its internal systems more configurable and data-driven. Users can now edit ALL visual and audio elements of Immersive Storms on a per-biome basis for each weather condition.

- Added NeoForge support via a universal jar and the Yumi MC Foundation Library.
- Rewrote all major systems to be set via config-based environment attributes instead of relying on hard-coded values in the advanced config.
- Removed the biome config.
